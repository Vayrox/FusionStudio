Trademark check

Will the image pass the filters?

Vor dem Seedance-Video pruefen ob das Bild von Trademark-Filtern (Higgsfield, Kling, etc.) blockiert wird. Funktioniert auch fuer beliebige extern hochgeladene Bilder. GPT-4o Vision liefert einen Risk-Score 0–100.

Vision-driven prompts

Generate prompts from any image

Lade ein Creature-Bild hoch und erzeuge alle Seedance / Kling Video-Prompts (Step 5 Transformation, Step 6 Showcase, Showcase Image, Action Scene) ausserhalb der Pipeline. Vision liest die Anatomie, GPT-4o schreibt die Prompts.

FFmpeg silence cutter

Trim narration pauses automatically

Narration-Pausen erkennen und entfernen. Lade ein MP3 / WAV / M4A hoch, FFmpeg analysiert Stille-Regionen, schneidet sie raus und liefert eine bereinigte MP3 zurueck. Originaldatei bleibt unangetastet.

Silence Detection

Audio unter diesem Pegel zaehlt als Stille. Niedriger = empfindlicher.
Nur Stille die laenger als das ist, wird erkannt.

Cut Offsets

So viel Stille NACH einer Voice-Line behalten, bevor geschnitten wird.
So viel Stille VOR der naechsten Voice-Line behalten.
Erst eine Audio-Datei hochladen.
